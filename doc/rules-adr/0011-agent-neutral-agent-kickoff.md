# 0011. エージェントに依存しない形にし、リポ名を agent-kickoff にする

- 状態：承認
- 日付：2026-10-21
- 関連：[0002](0002-public-template-repo-no-skill.md)・[0007](0007-subagent-model-assignment.md)・[0008](0008-pr-review-in-session-and-at-claude.md)

## 背景

ルールとテンプレートは Claude Code を前提に書かれていた。入口のファイルが `CLAUDE.md` で、文中の「Claude」や `reviewer` サブエージェントもそのまま書かれていた。

他のコーディングエージェントでも同じルールで開発できるようにしたい。`AGENTS.md` は複数のエージェントが読む共通の入口になりつつあり、Claude Code も `CLAUDE.md` がなければ `AGENTS.md` を読む。

## 決定

- 入口は `AGENTS.md` を正にする。`CLAUDE.md` は `@AGENTS.md` の取り込みと、Claude 固有の指示だけにする。
- `doc/rules.md` の本文は中立に書く。
  - 「Claude」は「エージェント」と呼ぶ。
  - サブエージェントは「役割（探索・ログ要約・レビュー）」として書く（8 章）。仕組みがないエージェントは、同じ手順を自分で行う。
  - エージェントごとの設定は付録 B に置く。今は Claude Code（B-1）だけ。
- 他のエージェント専用の設定は、実際に使うときに付録 B と設定ファイルを足す。
- devcontainer では、Claude Code を入れるかを引数 `INSTALL_CLAUDE_CODE` で切り替える（既定は入れる）。
- リポ名を `claude-kickoff` から `agent-kickoff` に変える。
- キックオフで相談する相手（チャット）も、Claude に限らない書き方にする。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| `AGENTS.md` だけを置く | Claude 固有の指示を置く場所がない。`AGENTS.md` を読めない Claude Code の版や設定もある |
| `CLAUDE.md` を `AGENTS.md` へのシンボリックリンクにする | Windows ではシンボリックリンクが扱いにくい |
| よく使われるエージェントの設定を最初から全部同梱する | 使わないものを保守することになる |
| リポ名 `dev-kickoff` | AI エージェント向けであることが伝わりにくい |
| リポ名 `project-template` | 何のテンプレートか分かりにくい |

## 結果

- 良くなること：Claude Code 以外のエージェントでも、`AGENTS.md` と rules だけで同じ進め方ができる。
- 引き受けること：
  - 入口のファイルが 2 つになる。
  - 「役割」は、サブエージェントの仕組みがないエージェントでは手順として守るしかない。
  - 古い名前（`claude-kickoff`）を書いた所を直す必要がある。GitHub の転送はあるが、メモリや既存の案件には古い名前が残る。
