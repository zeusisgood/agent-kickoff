# 0008. PR レビューはセッション内で行い、必要なときだけ @claude で呼ぶ

- 状態：承認
- 日付：2026-10-21
- 関連：[0007](0007-subagent-model-assignment.md)・付録 A-4

## 背景

PR を Claude にレビューさせたい。ただし API の従量課金はしたくない。

## 決定

- PR を出す前に、セッション内でレビュー用サブエージェント `reviewer` を必ず通す。
- もう一度見てほしい PR や Dependabot の PR は、ユーザーが PR のコメントで `@claude` を呼ぶ。
- `@claude` 用の GitHub Actions は、サブスクリプション用トークン `CLAUDE_CODE_OAUTH_TOKEN`（`claude setup-token` で作る）で認証する。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| セッション内のレビューだけ | GitHub 上に指摘が残らない。第三者の目を入れたいときに手段がない |
| PR のたびに Actions で自動レビュー | Claude が書いて自分でレビューした PR に重ねても得るものが少ない。push のたびに動き、利用枠を食う |
| API キーで認証する | 従量課金が発生する |

## 結果

- 良くなること：利用枠を無駄にせず、必要なときだけ別の目が入る。API 課金がない。
- 引き受けること：
  - `@claude` を呼び忘れることがある。
  - トークンはリポごとにシークレットとして登録する必要がある。
  - 利用枠は普段の Claude Code と共有になる。
  - 公開リポでは、フォークからの PR では動かない。
