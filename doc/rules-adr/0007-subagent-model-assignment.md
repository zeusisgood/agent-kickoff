# 0007. サブエージェントは役割ごとにモデルを割り当て、仕組みの詳細は公式文書に任せる

- 状態：承認
- 日付：2026-10-21
- 関連：rules 8 章・[0008](0008-pr-review-in-session-and-at-claude.md)

## 背景

大量の出力を生む作業（探索・ログ）をメイン会話から外したい。同時に、安いモデルを使える所では使いたい。一方で、Claude Code の仕組み（設定項目・環境変数・挙動）は更新が多く、ルールに書き写すとすぐ古くなる。

## 決定

| 名前 | 役割 | モデル | ツール |
|---|---|---|---|
| `Explore` | 探索（組み込みを上書き） | `haiku` | 読み取りのみ |
| `log-summarizer` | テスト・ビルドのログ要約 | `haiku` | 読み取り＋Bash |
| `reviewer` | PR 前のレビュー（必須） | `sonnet` | 読み取り＋Bash |

- 実装本体はメイン会話で行う。
- ルールには、役割・モデルの別名・ツールの範囲だけを書く。仕組みは公式文書（<https://code.claude.com/docs/en/sub-agents>）へのリンクに任せる。
- 運用に効く注意点（Explore は `CLAUDE.md` を読まない）だけは、ルールに残す。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 公式文書へのリンクだけ置く | 役割とモデルの割り当てが毎回 Claude 任せになり、ぶれる |
| 設定項目や環境変数まで書き写す | 公式文書が変わるとすぐ古くなる |
| レビューも `haiku` にする | レビューには質が要る |
| 実装もサブエージェントに任せる | 文脈の共有が多く、往復も多いので、メイン会話のほうが向いている |

## 結果

- 良くなること：メイン会話の文脈が汚れにくい。利用枠の消費を抑えられる。モデルの別名は常に最新版を指すので、更新に強い。
- 引き受けること：サブエージェントの利用分もメインと同じ利用上限に数えられる。Explore に守らせたい規則は、依頼文に書く必要がある。
