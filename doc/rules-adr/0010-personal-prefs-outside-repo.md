# 0010. 個人的な設定はリポに含めず、チャットだけで使う

- 状態：承認
- 日付：2026-10-21
- 関連：[0002](0002-public-template-repo-no-skill.md)

## 背景

元のルールには、ユーザー個人に向けた項目があった。

- 色を提案するときはカラーコードを付ける。
- conf を直してもらうときは vi の使い方を添える。

公開リポに置くのは、一般的なルールだけにしたい。

## 決定

- 個人的な設定はリポに含めない。claude.ai のユーザー設定（チャット）だけで使う。
- Claude Code には渡さない。
- ルールの「ユーザーとのやり取り」には、一般的な 2 項目だけを残す（上限は黙って付けずに聞く／確かめられないことは成果物で試してもらう）。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| リポに含める | 公開リポに個人的な事情が載る |
| ホストの `~/.claude/CLAUDE.md` を devcontainer にマウントする | ホストにファイルがないと起動に失敗する。準備の手間に見合わない |

## 結果

- 良くなること：公開リポに個人的な事情が載らない。
- 引き受けること：Claude Code からの指示には、vi の使い方などが付かない。
