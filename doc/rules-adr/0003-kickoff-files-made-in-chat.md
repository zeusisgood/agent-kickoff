# 0003. 仕様書・devcontainer・CLAUDE.md はチャットで作る

- 状態：承認
- 日付：2026-10-21
- 関連：[0002](0002-public-template-repo-no-skill.md)

## 背景

キックオフで作るファイル（仕様書・devcontainer・`CLAUDE.md` の案件固有部分）を、チャット（claude.ai）と Claude Code のどちらで作るかを決める必要があった。

## 決定

- 案件固有のファイルは、チャットでの相談の中で作ってユーザーに渡す。ユーザーが自分でリポに置く。
- Claude Code への最初の指示文も、チャットで書く。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 全部 Claude Code で作る | Claude Code を devcontainer の中で動かすには、devcontainer が先に要る（鶏と卵の問題） |
| ルールだけ Claude Code が公開リポから取ってくる | コンテナの通信制限に引っかかる可能性がある。最初の 1 手が増える |
| チャットから PR を出して受け渡す | 自分で置くほうが分かりやすく、中身も確かめられる |

## 結果

- 良くなること：中身を相談して決める作業と、ファイルを作る作業が同じ場所で済む。コンテナより先に全部が揃う。
- 引き受けること：ファイルを手で置く手間がある（テンプレートで共通部分を減らしている）。
