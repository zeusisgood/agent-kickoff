# 0016. 原本のライセンスを CC0-1.0 にする

- 状態：承認
- 日付：2026-10-21
- 関連：[0002](0002-public-template-repo-no-skill.md)

## 背景

原本を公開し、GitHub のテンプレートとして使えるようにする。ライセンスがないと、法律上は他人が複製して使えない（0002 の未決事項）。

テンプレートから作ったリポには、原本のファイルがそのまま複製される。そのため、原本のライセンスの条件は、すべての案件に付いて回る。案件は、それぞれ自分のライセンスを付ける。

中身はコードではなく、文章（rules・ADR）と設定ファイル。特許の条項は、ほぼ関係しない。

## 決定

- 原本のライセンスは CC0-1.0 にする。本文は `LICENSE` に置く。
- テンプレートから作った案件では、`LICENSE` を案件のライセンスに置き換える。ライセンスを付けないなら削除する（README の手順・`KICKOFF.md` の渡すもの）。
- 既存のリポに入れるときは、`LICENSE` をコピーしない。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| MIT | 著作権表示を残す義務が、すべての案件に付く |
| CC BY 4.0 | クレジットの義務が、すべての案件に付く。設定ファイルには向かない |
| MIT-0・0BSD | 条件がない点は同じ。ただしソフトウェア向けで、文章が中心の原本には CC0 のほうが合う。[github/gitignore](https://github.com/github/gitignore) など、複製して使うファイル集にも CC0 の前例がある |
| Unlicense | 日本では著作権を完全には放棄できず、扱いが曖昧。CC0 には、放棄できないときの代わりの許諾がある |
| ライセンスを付けない | 他人が複製して使えず、テンプレートにする意味がない |

## 結果

- 良くなること：案件に条件が残らず、どのライセンスでも付けられる。名前の表示も要らない。
- 引き受けること：
  - 原本の作者として名前を残せない。
  - `LICENSE` を置き換え忘れると、案件が意図せず CC0-1.0 になる。README と `KICKOFF.md` の手順で防ぐ。
